# Repository Security

## Intended Users
This repository is intended for me to store and develop my CSE 3000
assignments and work, and for the professor to review my work.

## Security Risks
The risk is relatively low for this class becasue it has no sensitive
information or data. At worst someone could possibly copy my assignments or, if given
write access, modify my code and affect my work. Though accidentally uploading
passwords or any private or sensitive information could create a more serious
risk.

## Security Approach
For a small, individual coursework repository, I do not consider a
CODEOWNERS file or mandatory pull-request reviews necessary at this
stage. These controls would be more useful if other people contributed
to the code.

My approach is to keep passwords and private data out of
the repository, check files before committing them, and limit write
access to people who need it.
