# Security
This file is intended to describe the measures I am taking to ensure that my repo remains secure.

## Intended Users
The intended users of the code in my repo are myself, Professor [Name], and approved tools such as Gradescope. I am the only person with permission to push or merge files to this repo. However, since the repo is public, anyone has access to and can view the files in this repo. 

## Risk of Security Threats
The risk of security threats is extremely low, as the repo simply contains class assignments and I am the only person with permission to alter the files found in this repo.

## Steps to Secure
To secure this repo, I configured a ruleset for pull requests on my main branch, which restricts deletion, blocks force pushes, and requires that changes to any files or the addition of any files must go through a pull request before being merged into the main branch.
